# LLM Agent QA Demo

Небольшой демонстрационный проект, показывающий подход к проверке LLM-агента: контракт API, сценарии использования, обработку ошибок и оформленный QA-отчёт.

> В репозитории используется детерминированный демонстрационный агент. Он не обращается к реальной модели и не требует API-ключа. Так можно воспроизводимо проверять логику до подключения LLM-провайдера.

## Что проверяется

- корректный ответ на обычный запрос;
- отказ от пустого сообщения;
- вежливый ответ на вопрос вне поддерживаемого сценария;
- неизменность структуры API-ответа.

## Стек

- Python 3.11+
- FastAPI
- pytest

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000/docs` и отправьте запрос в `POST /answer`:

```json
{"message": "Как подготовить проект к запуску?"}
```

## Проверка

```bash
pytest
```

Подробности сценариев и пример QA-отчёта находятся в [qa/report.md](qa/report.md).

## Как подключить реальную модель

Функция `build_answer` в `app/agent.py` — единственная точка замены. Вместо демонстрационной логики можно подключить адаптер к OpenAI-compatible API, локальной модели или другому провайдеру. Секреты следует хранить только в `.env`, не добавляя файл в Git.
