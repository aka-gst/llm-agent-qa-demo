# QA-отчёт: демонстрационный LLM-агент

## Цель

Проверить базовые пользовательские сценарии и стабильность контракта API до подключения реальной модели.

## Сценарии

| ID | Сценарий | Ожидаемый результат | Статус |
| --- | --- | --- | --- |
| QA-01 | Вопрос о запуске проекта | Ответ со статусом `ok` и ориентиром на README | PASS |
| QA-02 | Пустое или состоящее из пробелов сообщение | Понятная ошибка, без исключения приложения | PASS |
| QA-03 | Вопрос вне сценария | Запрос уточняющего контекста | PASS |
| QA-04 | Проверка структуры ответа | В ответе всегда есть `status` и `answer` | PASS |

## Результат

Все четыре сценария покрыты автоматическими тестами `pytest`. При подключении реальной LLM стоит дополнить набор проверками на таймауты, ограничения токенов, обработку API-ошибок, безопасность промпта и оценку качества ответов на размеченном наборе запросов.
